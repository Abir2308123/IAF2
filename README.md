# KALĀ-KSHETRA | Interactive Indian Art Map (CO1 Project) 🎨🇮🇳

**Course Outcome 1 (CO1) Submission**  
*Interactive Web Application built using Leaflet.js, HTML5, Vanilla CSS, and JavaScript.*

---

## 📖 Project Overview
KALĀ-KSHETRA is an interactive map detailing India's rich artistic traditions, cave murals, monolithic architecture, and folk art forms across 8 primary syllabus locations:

1. **Ajanta Caves** (Maharashtra) – Buddhist Wall Frescoes & Bodhisattva Padmapani
2. **Ellora Caves** (Maharashtra) – Kailasa Monolithic Temple Architecture
3. **Thanjavur / Tanjore** (Tamil Nadu) – 22K Gold Foil Leaf Deities & Chola Bronzes
4. **Khajuraho** (Madhya Pradesh) – Nagara Sandstone Relief Carvings & Apsaras
5. **Madhubani / Mithila** (Bihar) – Double-line Folk Motifs, Peacocks & Dyes
6. **Warli Region** (Maharashtra) – Rice Paste Stick Figures & Tarpa Dance Spiral
7. **Puri** (Odisha) – Pattachitra Scroll & Palm Leaf Paintings
8. **Jaipur** (Rajasthan) – Rajasthani Miniature Paintings & Jharokha Art

---

## 🚀 How to Open and Review

1. Unzip the downloaded file: `KALA_KSHETRA_Indian_Art_Map_CO1.zip`
2. Open the folder and **double-click `index.html`** in any web browser (Chrome, Safari, Edge, Firefox).
3. No installation or server configuration is required; it runs standalone!

## ✨ Features Highlight

- 🗺️ **Interactive Leaflet Map**: 4 Map themes (Midnight Dark, Parchment, Classic, Satellite).
- 🪟 **Slide-in Art Detail Drawer**: Complete breakdown of era, dynasty, pigments, motifs, and audio guide narration.
- 🔊 **Web Speech Audio Guide**: Listen to historical commentary for each site.
- 🎨 **DIY Indian Folk Art Studio**: Practice drawing Warli stick figures, Madhubani double lines, and Tanjore gold art with stencil stamps and downloadable PNG output.
- 🎵 **Ambient Classical Soundscape**: Web Audio synthesizer generating Tanpura/Sitar drone.
- 🧩 **Art History Quiz**: Interactive 5-question evaluation with instant score reports.
- 📋 **Syllabus Checklist**: Table detailing CO1 coverage with map jump shortcuts.
